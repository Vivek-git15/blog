# Fieldnotes

A responsive editorial blog landing page built with plain HTML, CSS, and JavaScript. It includes topic filtering, story search, a mobile navigation menu, and an interactive newsletter signup confirmation.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

The typography uses system serif and sans-serif fonts, so the site works offline. Newsletter submission is a front-end demo and does not send or store email addresses.
